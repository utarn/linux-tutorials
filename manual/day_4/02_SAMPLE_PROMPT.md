## โจทย์ (Prompt ภาษาไทย)

ต้องการสร้างแอพพลิเคชั่นเกี่ยวกับการทำ todo โดยใช้ภาษา typescript next.js ใช้ฐานข้อมูล postgresql ใช้ orm prisma 7 โดยสร้าง docker compose รัน postgresql สำหรับใช้ในโปรเจคเท่านั้น, ช่วย map port ใน docker compose กับ host port โดยหา port ที่ว่างจากการใช้งานหากชนกับ instance อื่น

โดยที่ข้อมูลของรายการแต่หลายรายการเนี่ยจะประกอบไปด้วยชื่อของสิ่งที่ต้องทำวันที่เวลาเดท ไลน์ แล้วก็ความเร่งด่วน ผู้ใช้งานสามารถที่จะปรับลำดับเลื่อนขึ้นเลื่อนลงได้นะแล้วก็สามารถจามาร์คมันว่าทำเสร็จแล้วหากว่าทำเสร็จแล้วมันควรจะหายจากหน้าจอแล้วก็ไอ้ของที่หายจากหน้าจอที่ทำเสร็จแล้วเนี่ยควรจะไปอยู่อีกหน้านึงเพื่อให้ดูด้วยว่าเคยทำอะไรไปบ้างเรื่องลำดับเวลาจากใหม่ไปหาเก่าแต่ว่าตัวหน้าที่ยังไม่ได้ทำเนี่ยควรจะเรียงลำดับจากเก่าไปหาใหม่ไหมก็คือของที่จะต้องทำน่ะขึ้นก่อนเร็ว เราอยากได้เว็บที่มันมีสีสันสดใสแบบสีพาสเทล ใช้เฟรมเวิร์คซีเอสเอสอะไรก็ได้ที่เหมาะสมกับมันแต่ว่าอยากได้สีพาสเทลที่มันดูลุคเหมือนที่มันเหมาะสมสำหรับเด็กใช้งาน 

แอปมีการล็อกอินด้วย username/password เป็นหลัก
ใช้ framework เวอร์ชันล่าสุด สอบถามข้อมูลจาก context7
หากไม่มั่นใจหรือไม่พบข้อมูล ให้หา websearch จาก brightdata
