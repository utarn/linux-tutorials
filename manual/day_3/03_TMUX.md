# คู่มือ tmux และการตั้งค่าสำหรับ Vibe Coding (Claude Code / Linux Terminal)

เอกสารแนะนำการติดตั้ง การใช้งานคำสั่งพื้นฐาน และการตั้งค่า `tmux` บน Ubuntu Linux เพื่อให้รองรับการเลื่อนหน้าจอ (Mouse Scroll) อ่านคำตอบจาก Claude Code หรือ CLI AI tools ได้อย่างราบรื่น

---

## ⚡ คำสั่งที่ต้องรู้ก่อน (Tmux Survival Kit)

รวมคำสั่งสำคัญที่ต้องรู้สำหรับผู้เริ่มต้นใช้งาน tmux บน Linux:

```bash
# 1. ติดตั้ง tmux บน Ubuntu Linux
sudo apt update && sudo apt install -y tmux

# 2. สร้างเซสชันใหม่ชื่อ 'vibe'
tmux new -s vibe

# 3. ออกจากเซสชันชั่วคราว (Detach) โดยที่งานในเซสชันยังรันอยู่ปกติ
# กดปุ่ม: Ctrl+b จากนั้นกด d

# 4. ดูรายการเซสชันทั้งหมดที่กำลังทำงานอยู่
# (จะได้เห็น ID/ชื่อเซสชัน เช่น [vibe] ก่อนเข้าไป Attach)
tmux ls

# 5. กลับเข้าเซสชัน (Attach) — ระบุตาม ID/ชื่อจากผลลัพธ์ของ `tmux ls`
tmux attach -t <id>

# 5.1 กลับเข้าเซสชันอีกวิธี ขับด้วยชื่อเซสชัน เช่น 'vibe' (attached สุดท้ายที่ detach)
tmux attach -t vibe

# 5.2 คำสั่ง alias (ทางลัด) ของ `tmux attach` — ใช้ได้เหมือนกัน
tmux attach-session -t vibe

# 6. ลบเซสชันชื่อ 'vibe' เมื่อใช้งานเสร็จเรียบร้อย
tmux kill-session -t vibe
```

## 🎯 สถานการณ์ตัวอย่าง: นักวิทยาศาสตร์ผู้ใช้ Windows ย้ายมาทำ Vibe Coding บน Linux

> **Scenario:** คุณเป็นนักวิทยาศาสตร์ที่ย้ายจากการสั่งรันโค้ดบน Windows GUI มาใช้ Linux server เพื่อรัน AI Coding Agent (เช่น Claude Code หรือ CLI AI tools) เพื่อให้ AI เขียนโค้ดวิเคราะห์ข้อมูลให้
> 
> **ปัญหาที่เจอ:** เวลาสั่งให้ AI วิเคราะห์ไฟล์ข้อมูลวิจัยขนาดใหญ่ ถ้าการเชื่อมต่ออินเทอร์เน็ตหลุด คำสั่งที่ AI กำลังทำงานอยู่จะดับทันที! หรือเวลา AI ตอบคำสั่งยาวๆ แล้วเลื่อนหน้าจอ (Scroll) ย้อนกลับไปดูไม่ได้
> 
> **ทางออก:** ใช้ `tmux` เปิดเซสชันทิ้งไว้ แม้ปิดโน้ตบุ๊ก Windows กลับบ้าน งานบน Linux ก็ยังคงรันต่อไม่ดับ และตั้งค่าเมาส์ให้เลื่อนดูหน้าจอย้อนหลังได้อย่างลื่นไหล!

## 1. การติดตั้ง tmux บน Ubuntu Linux

### 🎯 สิ่งที่ต้องการเรียนรู้
- วิธีการติดตั้งแพ็กเกจ `tmux` ผ่านระบบจัดการแพ็กเกจ `apt` บน Ubuntu

```bash
# อัปเดตฐานข้อมูลแพ็กเกจของ Ubuntu ให้เป็นปัจจุบัน
sudo apt update

# ติดตั้งโปรแกรม tmux ลงบนระบบ
sudo apt install -y tmux

# ตรวจสอบเวอร์ชันของ tmux ที่ติดตั้งสำเร็จ
tmux -V
```

## 2. การตั้งค่า `~/.tmux.conf` สำหรับ Claude Code / Vibe Coding (สำคัญมาก!)

### 🎯 สิ่งที่ต้องการเรียนรู้
- ตั้งค่าให้เมาส์สามารถเลื่อนหน้าจอ (Scroll) ดู Log หรือคำตอบยาวๆ จาก Claude Code ได้ทันที
- ขยายหน่วยความจำแถบย้อนหลัง (Scrollback Buffer) ไม่ให้ข้อความโดนตัด
- รองรับสีแบบ True Color เพื่อให้สีของโค้ดในเทอร์มินัลสวยงาม

### 🛠️ คำสั่งดาวน์โหลดและติดตั้ง `~/.tmux.conf` จาก Gist

ดาวน์โหลดคอนฟิกสำเร็จรูปจาก Gist มาใช้เป็น `~/.tmux.conf`:

```bash
# ดาวน์โหลด ~/.tmux.conf จาก Gist (Modern Tmux สำหรับ Remote SSH จาก Windows/macOS)
curl -fsSL -o ~/.tmux.conf https://gist.githubusercontent.com/utarn/5993ce2c0a970e2e6a3a191ac75a884e/raw/.tmux.conf

# ตรวจสอบว่าไฟล์ถูกสร้างมาเพื่อรองรับ
# - เมาส์เลื่อนดูหน้าจอ (Scroll) / ดู Log และคำตอบยาวๆ จาก Claude Code ได้ทันที
# - หน่วยความจำแถบย้อนหลัง (Scrollback) 50,000 บรรทัด ไม่ให้ข้อความโดนตัด
# - สี True Color เพื่อให้สีของโค้ดในเทอร์มินัลสวยงาม
# - คลิปบอร์ดเลื่อนผ่าน OSC 52 (คัดลอกจาก tmux ไปวางบน Windows/macOS ได้)
ls -la ~/.tmux.conf

# โหลดการตั้งค่าใหม่เข้าสู่ tmux ทันที
tmux source ~/.tmux.conf 2>/dev/null || echo "พร้อมใช้งาน! เมื่อเปิด tmux ครั้งต่อไป คอนฟิกจะทำงานอัตโนมัติ"
```

> **หมายเหตุ:** คอนฟิกนี้ใช้ Prefix เดิม `Ctrl+b` และเพิ่มปุ่มลัดโหลดคอนฟิกใหม่ `Ctrl+b` แล้วกด `r` (reload config ได้เลยโดยไม่ต้องออกจาก tmux) พร้อมทั้ง bind ปุ่ม `|` (แบ่งแนวตั้ง) และ `-` (แบ่งแนวนอน) โดยไม่ต้องกด Prefix ก่อน

## 3. ขั้นตอนการใช้งาน tmux ร่วมกับ Vibe Coding (Claude Code)

### 🎯 สิ่งที่ต้องการเรียนรู้
- วิธีการเริ่มเซสชัน tmux สำหรับรัน AI Agent
- วิธีแบ่งหน้าจอ (Split Pane) เพื่อพิมพ์โค้ดด้านหนึ่ง และดูผลการรันอีกด้านหนึ่ง
- วิธีเลื่อนหน้าจอ (Scroll) ย้อนหลัง

### 🧪 ขั้นตอนการปฏิบัติงาน (Run Commands)

```bash
# 1. สร้างโฟลเดอร์โครงการสำหรับงานวิจัย
mkdir -p ~/science-vibe-project

# 2. ย้ายเข้าไปในโฟลเดอร์โครงการ
cd ~/science-vibe-project

# 3. เปิดเซสชัน tmux ชื่อ 'claude-session'
tmux new -s claude-session

# --- ตอนนี้คุณจะเข้ามาอยู่ใน tmux ---

# 4. สั่งแบ่งหน้าจอเป็น ซ้าย-ขวา (กด Ctrl+b จากนั้นกด % )
# หรือรันคำสั่ง tmux split-window ด้านล่างนี้:
tmux split-window -h

# 5. สั่งแบ่งหน้าต่างล่าง (กด Ctrl+b จากนั้นกด " )
# หรือรันคำสั่ง split ด้านล่างนี้:
tmux split-window -v

# 6. หากต้องการเลื่อนดูข้อความที่ Claude Code ตอบยาวๆ ให้ใช้ล้อหมุนของเมาส์ (Mouse Wheel) สโครลได้เลยทันที!
# หรือกด Ctrl+b แล้วตามด้วย [ เพื่อเข้าสู่ Copy/Scroll mode (กด q เพื่อออกจาก mode สโครล)
```

## 4. สรุปปุ่มลัด (Shortcut Keys) ที่ใช้บ่อยใน tmux

ต้องกด **Prefix Key** (`Ctrl+b`) ก่อนเสมอ แล้วจึงกดปุ่มถัดไป:

| ปุ่มลัด | การทำงาน |
|---|---|
| `Ctrl+b` แล้วกด `d` | Detach ออกจากเซสชัน (ปล่อยให้งานรันอยู่เบื้องหลัง) |
| `Ctrl+b` แล้วกด `%` | แบ่งหน้าจอแนวตั้ง (ซ้าย-ขวา) |
| `Ctrl+b` แล้วกด `"` | แบ่งหน้าจอแนวนอน (บน-ล่าง) |
| `Ctrl+b` แล้วกด `r` | โหลดคอนฟิก `~/.tmux.conf` ใหม่ (จาก Gist) โดยไม่ต้องออกจาก tmux |
| ตัวอักษร `\|` (ไม่ต้องกด Prefix) | แบ่งหน้าจอแนวตั้ง ตามโฟลเดอร์ปัจจุบัน |
| ตัวอักษร `-` (ไม่ต้องกด Prefix) | แบ่งหน้าจอแนวนอน ตามโฟลเดอร์ปัจจุบัน |
| `Alt` + `ลูกศร` (ไม่ต้องกด Prefix) | ย้าย Cursor ไปยัง Pane ที่ต้องการ |
| `Ctrl+b` แล้วกด `ลูกศร` | ย้าย Cursor ไปยัง Pane ที่ต้องการ |
| `Ctrl+b` แล้วกด `c` | สร้างหน้าต่างใหม่ (Create Window) |
| `Ctrl+b` แล้วกด `n` / `p` | ไปหน้าต่างถัดไป / หน้าต่างก่อนหน้า |
| `Ctrl+b` แล้วกด `[` | เข้าสู่โหมดเลื่อนดูหน้าจอ (Scroll Mode) กด `q` เพื่อออก |
| `Ctrl+b` แล้วกด `z` | ขยาย Pane ปัจจุบันให้เต็มจอ (กดซ้ำเพื่อย่อกลับ) |
