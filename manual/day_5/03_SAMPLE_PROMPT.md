## สร้างแอพปลิเคชัน Todo ด้วย Next.js + Prisma 7 + PostgreSQL

## ภาษาไทย
เรามีโปรเจคอ้างอิงอยู่ที่ ../nextjs-boilerplate
สร้างแอพ Todo ให้ผู้ใช้งานสามารถทำ CRUD กับ task ได้
Task ประกอบด้วย ชื่อ, รายละเอียด, กำหนดการวันที่ และ ความสำคัญ

เก็บข้อมูลไว้ในฐานข้อมูล Postgresql ใช้ ORM SQLAlchemy
องค์ประกอบของแอปพลิเคชันให้รันผ่าน docker compose
Zod + Prettier + Fallow สำหรับตรวจสอบข้อมูลและจัดรูปแบบโค้ด
กำ Test coverage อย่างน้อย 80% ด้วย Vitest

ใช้ Context7 และ Brightdata Websearch สอบถามข้อมูล documentation ล่าสุด
Update CLAUDE.md สำหรับข้อมูลที่จำเป็นด้วย
/tdd

## English

I have a referenced project at ../nextjs-boilerplate.
Create the TODO app to allow the user to perform CRUD on tasks.
The tasks contains title, description, due date, and priority.

Store data in a PostgreSQL database using Prisma 7 ORM.
Compose the application to run through Docker Compose.
Use Zod + Prettier + Fallow for data validation and code formatting.
Ensure at least 80% test coverage using Vitest.

Use Context7 and Brightdata Websearch to query the latest documentation.
Update CLAUDE.md for necessary information.
